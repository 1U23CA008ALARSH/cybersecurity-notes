| Command      | Meaning                                                               |
| ------------ | --------------------------------------------------------------------- |
| `find`       | Search for files and folders.                                         |
| `grep`       | Search for specific text inside files.                                |
| `chmod`      | Change file or folder permissions.                                    |
| `chown`      | Change the owner of a file or folder.                                 |
| `whoami`     | Show the current logged-in user.                                      |
| `id`         | Display your user ID (UID), group ID (GID), and groups.               |
| `groups`     | Show the groups your user belongs to.                                 |
| `ps`         | Show currently running processes.                                     |
| `top`        | Display live system processes and resource usage.                     |
| `htop`       | An interactive version of `top` (if installed).                       |
| `kill`       | Stop a running process.                                               |
| `ip`         | Show or configure network interfaces and IP addresses.                |
| `ping`       | Test whether another device is reachable on the network.              |
| `traceroute` | Show the path packets take to a destination.                          |
| `ss`         | Display network connections and listening ports.                      |
| `netstat`    | Show network connections (older tool).                                |
| `curl`       | Transfer data to or from a server (often used for APIs and websites). |
| `wget`       | Download files from the internet.                                     |
| `zip`        | Compress files into a ZIP archive.                                    |
| `unzip`      | Extract files from a ZIP archive.                                     |
| `tar`        | Create or extract archive files.                                      |
| `uname`      | Show system information (kernel, OS).                                 |
| `hostname`   | Show or set the computer's hostname.                                  |
| `date`       | Display the current date and time.                                    |
| `uptime`     | Show how long the system has been running.                            |
| `free`       | Display RAM and swap memory usage.                                    |
| `lscpu`      | Show CPU information.                                                 |
| `lsblk`      | List storage devices and partitions.                                  |
| `nmap`       | Scan networks, hosts, and ports.                                      |
| `whois`      | Look up domain registration information.                              |
| `dig`        | Query DNS records.                                                    |
| `nslookup`   | Look up DNS information for a domain or IP.                           |
